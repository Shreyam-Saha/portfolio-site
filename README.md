# Portfolio Site

Modern, minimalist portfolio website built with React, Vite, and shadcn/ui.

## 🚀 Tech Stack

- **React 19** - UI library
- **Vite 7** - Build tool & dev server
- **Tailwind CSS 3** - Utility-first CSS framework
- **shadcn/ui** - Re-usable component library
- **Ant Design** - Additional UI components
- **Lucide React** - Modern icon library
- **React Router DOM** - Client-side routing
- **Vercel Analytics** - Web analytics

## 📦 Project Structure

```
src/
├── components/
│   ├── ui/              # shadcn/ui components
│   ├── home/            # Home page (shadcn-based)
│   ├── work/            # Work experience timeline
│   ├── projects/        # Projects showcase
│   ├── certifications/  # Certifications display
│   ├── contact/         # Contact form
│   └── navbar/          # Navigation
├── lib/                 # Utility functions
├── assets/              # Images & icons
└── constants/           # Static data

## 🎨 Design Features

- Modern cyber-wave color scheme (cyan & pink accents)
- Glassmorphism effects
- Smooth animations & transitions
- Fully responsive design
- Dark theme optimized

## 🛠️ Development

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview

# Lint code
npm run lint
```

## 📝 Adding shadcn Components

```bash
npx shadcn@latest add [component-name]
```

## 🌐 Deployment

Configured for Vercel deployment with automatic SPA routing.
